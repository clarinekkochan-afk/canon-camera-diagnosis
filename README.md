# Canon カメラ診断

撮りたいものや使い方、予算などの質問に答えることで、
自分に合ったCanonのカメラをTOP3形式で提案するWebアプリです。

🔗 Demo
https://canon-camera-diagnosis-3x1h.vercel.app/

## 制作背景

フォトグラファーとして活動する中で、

「カメラを始めたいけれど、種類が多くて違いが分からない」
「スペックを見ても、自分に必要な性能なのか判断できない」

という相談を受けることがありました。

また、カメラ自体の経験はあっても、Canonを初めて使う人にとっては、
マウントや機種ごとの特徴、中古機を含めた選択肢などを比較することは簡単ではありません。

そこで、専門用語やスペックから選ぶのではなく、
「何を撮りたいか」「どのように使いたいか」から
自分に合ったカメラを探せる診断アプリを制作しました。

## 主な機能

- 撮影目的を第1〜第3希望まで選択
- 新品・中古の希望を反映
- ボディ予算を考慮
- 暗所撮影・動体撮影・望遠撮影などの重要度を診断
- 動画撮影や持ち運びやすさを考慮
- カメラ経験や操作方法の好みを反映
- 所有レンズ・マウントを考慮
- 条件に合うCanonカメラをTOP3で表示
- おすすめ度や各機種の特徴を結果画面で比較
- Canon公式製品ページへの導線

## 診断について

回答内容から、ユーザーがカメラに求めている要素を数値化し、
各カメラに設定した性能データと比較しておすすめ機種を算出しています。

主に以下のような要素を診断に使用しています。

- ポートレート適性
- 動体撮影性能
- 暗所性能
- 望遠撮影適性
- 解像性能
- 動画性能
- 携帯性
- 操作性
- 信頼性

さらに、予算、新品・中古の希望、所有レンズなどの条件も加味し、
撮影性能だけではなく、実際に購入する際の条件も含めてランキングを作成しています。

## 掲載機種

現行機種だけではなく、中古市場で選択肢となる旧機種も含めて
Canon EOSシリーズを掲載しています。

ミラーレス・一眼レフの両方を対象とし、
RF / EF / EF-S / EF-Mなどのマウントも考慮しています。

価格については、新品・中古それぞれの参考価格を設定し、
予算との比較に利用しています。

※価格は変動するため、あくまで診断時の参考価格です。

## 工夫した点

### 1. スペックではなく「撮りたいもの」から選べる設計

初心者が「センサーサイズ」「連写性能」などのスペックから
カメラを選ぶことは難しいと考えました。

そのため、できる限り専門用語を使わず、
実際の撮影シーンや使い方について答えることで
必要な性能を判断できる質問設計にしています。

### 2. 「カメラ初心者」と「Canon初心者」を分けて考える

カメラそのものが初めての人だけでなく、
他メーカーからCanonへ移行する人も利用できるよう、
撮影経験や所有レンズについての質問を設けました。

### 3. 新品だけでなく中古機も候補に含める

予算によっては旧機種や中古機の方が適している場合もあるため、
現行製品だけに限定せず、過去のEOSシリーズも診断対象にしています。

単純に新しい・高価な機種ほど高評価になるのではなく、
用途と条件に合った機種を提案することを意識しました。
